## 📋 API ENDPOINTS REFERENCE

### OCR Endpoints

**Process Certificate:**
```
POST /ocr/process
Input: file (certificate image)
Output: {success, ocr_data, confidence, fields_detected}
Time: 2-5 seconds
```

**Verify Certificate:**
```
POST /ocr/verify
Input: file, stored_credential
Output: {success, final_verdict, authenticity, match_score}
Time: 2-5 seconds
```

**Batch Process:**
```
POST /ocr/batch-process
Input: files[] (multiple images)
Output: {success, results[], processed, failed}
Time: 2-5 seconds per image
```

**Compare Images:**
```
POST /ocr/comparison
Input: files[] (2+ images of same cert)
Output: {consistency_analysis, confidence_score, field_consistency}
Time: 5-10 seconds
```
